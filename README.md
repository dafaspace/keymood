# Keymood

A circle of fifths you can hear - explore keys, modes, chords and how they relate,
find the next key for the mood you want, practise with a metronome in any meter and
a dice that rolls keys and progressions. Camelot and solfège notation, an ear-training
quiz, a sampled piano, and shareable links. (Formerly "Another Circle of Fifths".)

**▶ Live app: https://keymood.app**

Works offline and installs to your home screen — open the link and choose
"Add to Home Screen".

## Features
- Interactive circle of fifths (major + minor rings), light & dark themes
- Tonal / Modal views, diatonic chords, key relationships
- Camelot wheel & solfège notation, transpose, playback
- Ear-training quiz
